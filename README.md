# 📊 Student Grades Analyzer (Pandas)

A Python script that uses the Pandas library to clean, analyze, and generate reports from student grade data.

## ✨ Features
- Reads raw data from a CSV file.
- **Data Cleaning:** Removes duplicate rows and handles missing values (`NaN`).
- **Statistical Analysis:** Calculates average, max, and min scores.
- Identifies the top student.
- **Data Grouping:** Groups data by gender to calculate average scores.
- Adds a `Status` column (Pass/Fail).
- **Export:** Saves the final cleaned data to `final_report.csv`.
